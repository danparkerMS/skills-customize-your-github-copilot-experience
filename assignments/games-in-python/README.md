
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic word-guessing game while practicing Python strings, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Hangman game where the player guesses letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a secret word from a predefined list
- Accept one letter guess at a time from the player
- Display the current word progress using underscores for unguessed letters
- Track guessed letters and the number of incorrect guesses remaining
- End when the player guesses the word or uses all available attempts
- Display a clear win or loss message and reveal the secret word
